🚀 4. New Client Onboarding & Chat-Driven App Creation Flow

End-to-End Chat-Driven Factory Pipeline

  1. Engagement-First Intake: The client initiates contact via Telegram or landing page. The bot conducts a 2-3 step interactive survey (AI adoption level, goals, business identity) with zero disruptive page reloads.
  2. Dedicated Topic & Bot Binding: Hermes automatically provisions a dedicated private forum topic in the `Neoll-Labs.tlg` supergroup and assigns the appropriate venture bot (e.g., Marco Silva `@meta_ceo_bot` for SaaS/Chat2App, Robert for ExpatHousing, Yokochi for EcoPool).
  3. Chat-Driven Spec Gathering: The client talks directly with the bot in Telegram. The bot gathers application requirements, target users, core features, and data needs conversationally.
  4. Hermes Factory Provisioning: Upon spec confirmation, Hermes spins up an isolated Git worktree (`C:\Users\ai\ao\projects\`) and instantiates a native Kanban board (`kanban.db`).
  5. Supabase & Vercel Infrastructure: Hermes provisions exactly 1 dedicated Supabase project and connects a Vercel project under team scope `neoll-labs-projects`.
  6. Staging Preview with Chat Banner: Code is pushed to the staging branch, deploying instantly to `.staging.neoll-labs.com` complete with an embedded client review chat banner.
  7. Interactive Telegram Promotion Gate: The bot sends the staging preview link to the client in Telegram with interactive inline approval buttons:
    [ ✅ Approve & Ship to Prod ]   [ ✏️ Request Changes ]
    Once approved, the app promotes automatically to production (`.neoll-labs.com`).

💡 O Padrão de Pedido Recomendado (3-Step Agentic Request)

Para obter execuções autónomas imediatas e de alta precisão em qualquer tópico, estrutura o teu pedido em 3 pontos:

1. O Quê (Feature / Correção)

Especifica o objetivo funcional claro (ex: "Adiciona um filtro de setor no topo da página de eventos").

2. Critério de Aceitação

Como sabemos que está pronto (ex: "Deve guardar o filtro na URL e atualizar a lista sem recarregar").

3. Ação Autónoma

O agente escreve o código, testa o build, faz commit e publica em produção/staging com o link de verificação.
